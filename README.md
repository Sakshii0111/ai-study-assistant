# Smart AI Study Assistant

## Overview

Smart AI Study Assistant is a GenAI-powered web application that helps students learn faster and smarter. It uses Large Language Models (LLMs) to generate explanations, notes, quizzes, and answers to user queries in real time.

---

##  Features

*  Generate simple explanations for any topic
*  Create short and structured notes
*  Generate quizzes for practice
*  Chat with AI to clear doubts
*  Adaptive learning modes (Beginner, Intermediate, Advanced)

---

##  Tech Stack

* Python
* Streamlit
* OpenAI API (LLM)
* Prompt Engineering

##  Installation & Setup

1. Clone the repository:

```
git clone https://github.com/your-username/ai-study-assistant.git
cd ai-study-assistant
```

2. Install dependencies:

```
pip install -r requirements.txt
```

3. Add your API key:
   Create a `.env` file and add:

```
OPENAI_API_KEY=your_api_key_here
```

4. Run the app:

```
streamlit run app.py
```
